# Meeting to Action AI

Meeting to Action AI is a functional product prototype that turns messy meeting notes into structured action briefs for product, design, and operations teams.

The tool extracts decisions, action items, owners, risks, open questions, and follow-up messages from unstructured notes. It is designed to help teams leave meetings with clearer ownership and faster next steps.

## Why I Built This

Cross-functional teams often leave meetings with useful discussion but unclear ownership. This project explores how AI can support team alignment by transforming messy notes into clear, actionable outputs.

## Core Features

- Meeting notes input
- Meeting type selector
- Structured action brief generation
- Decision extraction
- Action item ownership
- Priority labels
- Risk and open question detection
- Follow-up message generator
- Copyable team update
